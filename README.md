This repository contains SQL queries that I have written while practicing data analysis concepts and preparing for interviews.

The focus of this repository is on writing clear and practical SQL that can be used in real reporting and analytics scenarios, rather than overly complex queries.

Most examples are based on common situations like customer analysis, sales summaries, and performance reporting.

Topics covered
Basic select queries
Filtering and sorting data
Group by and aggregations
Joins used in reporting
Subqueries and simple window functions
